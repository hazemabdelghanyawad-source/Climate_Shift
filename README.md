# Climate Shift

Interactive Arabic climate education app built with React, TypeScript, Vite, Tailwind CSS, and Lucide React.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## GitHub Pages

The Vite base is configured for a repository named `climate-shift`:

`/climate-shift/`

If your repository has a different name, update `base` in `vite.config.ts`.
